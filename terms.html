利用規約

最終更新: 2026-10-01

本規約は、「世界のなかみ」（以下「当チャンネル」）が運営する投稿支援ツール「sekainonakami」（以下「本ツール」）に適用される。

1. 本ツールの目的

本ツールは、当チャンネルが制作した動画を、当チャンネル自身のアカウントから各プラットフォーム（YouTube、Instagram、TikTok）へ投稿するために使う内部ツールである。第三者への提供は行わない。

2. 利用者

本ツールを利用するのは、当チャンネルの運営者および運営者が許可した共同制作者に限る。

3. 禁止事項

各プラットフォームの利用規約、コミュニティガイドライン、法令に反する内容の投稿に本ツールを用いてはならない。

4. 免責

本ツールは現状有姿で提供する。本ツールの利用により生じた損害について、運営者は故意または重過失がある場合を除き責任を負わない。

5. 変更

本規約は予告なく変更することがある。変更後の規約は本ページに掲載した時点で効力を生じる。

6. 連絡先

お問い合わせは、当チャンネルの YouTube または Instagram（@sekainonakami）のメッセージ、または GitHub の Issue から。
